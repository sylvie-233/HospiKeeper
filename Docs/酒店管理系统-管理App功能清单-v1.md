# 云栖民宿 · 管理端 App（老板版 · MAUI）｜ 功能清单（v1）

定位：面向**老板/管理员的桌面端简化版移动 App**，与前台桌面端、游客 Web 共用同一数据库、实时同步。核心原则：**知情 + 轻决策**——看得见经营全貌，动得了两件轻事（取消预定、快捷改价）；涉及钱和证件的柜台业务一律回前台桌面端。

> 对应原型：`Docs/酒店管理系统-管理App原型-v1.html`（可直接双击打开，手机机身样式，演示数据内置，登录 admin / 123456）
> 内部联动：`Docs/酒店管理系统-原型-v1.html`（桌面端）、`Docs/酒店管理系统-游客预订Web原型-v1.html`（游客 Web）、`Docs/民宿管理系统-数据库设计-v1.sql`
> 版本：v1 ｜ 日期：2026-11-25

## 一、登录

1. 账号密码登录，样式沿用桌面端登录规范
2. **仅 ADMIN 角色可登录**（复用 `sys_user`，前台 FRONT 账号拒绝）
3. 登录成功写入操作日志；支持退出登录（二次确认）

## 二、经营看板（默认首页）

1. 今日营收 Hero 卡：大数字展示 + 较昨日涨跌胶囊（涨红跌绿，与桌面端口径一致）
2. 三项核心指标卡：当前入住率（剔除维修/停用）、待到店预定数、押金占用合计
3. 近 7 日营收柱状图（今日高亮，数据与桌面端报表同源）
4. 待处理列表（需要老板知晓/决断的事）
   - 条目类型：WEB 渠道新预订、待保洁确认、今日预退提醒
   - 默认显示前 3 条，超出折叠为「查看全部 N 条」，可展开/收起
   - 条目可点击跳转对应页面（预订 → 预定管理、保洁 → 房态、预退 → 在住）
   - 「预定」Tab 角标 = 待处理条目数，为 0 时隐藏
5. 顶部同步状态条：数据同步指示 + 最近同步时间

## 三、房态总览（只读）

1. 按楼层 / 按房态双维度筛选（胶囊筛选条）
2. 三列房卡网格：**全覆盖房态色 + 白字**（配色与桌面端看板完全一致：绿空闲/蓝入住/紫预定/青打扫/金维修/灰停用）
3. 图例统计条：六种房态数量一览
4. 点击房卡弹出底部抽屉详情：楼层/标价、当前房态、在住客人信息、预定客人信息；标注"管理端只读，房态操作回前台"

## 四、预定管理（含唯一写操作之一）

1. 状态筛选：全部 / 待到店 / 已转入住 / 已取消（分段选择器，与 `reservation.status` 一致）
2. 预订单卡片列表：预订号（等宽字体）、客人、渠道标签（**游客在线 / 前台代订**）、房型/房号、到店时间
3. WEB 渠道待到店单标注「未分配」房号提示（呼应房型预订模型：房号到店转入住时由前台分配）
4. 点击预订单弹底部抽屉详情：完整单据信息
5. **取消预定**（写操作）：仅待到店单可取消，二次确认，库存即时回补，写操作日志

## 五、在住列表（只读）

1. 在住房卡列表：房号/客人/房型/入住→预退日期/单价/押金/追加消费/经办前台
2. 头部显示押金占用合计
3. 标注"结算请回前台桌面端办理"，入口按钮提示不跳转办理

## 六、我的

1. 个人信息卡：头像、姓名、民宿名、ADMIN 标识、数据同步状态
2. **快捷改价**（写操作之二）：底部抽屉列出三个房型当前定价 → 逐房型调价（校验有效值、不允许原价重复）→ 即时同步前台、写入操作日志，附影响说明
3. 操作日志（二级页）：按类型筛选（预定/改价/登录等），展示操作人/对象/明细/时间
4. 关于本应用：版本与功能边界说明
5. 退出登录

## 七、公共能力

1. 手机 App 形态：竖屏布局 + 底部 5 Tab 导航（看板/房态/预定/在住/我的）+ 二级页返回
2. 底部抽屉（Bottom Sheet）交互：房间详情 / 预定详情 / 改价表单
3. Toast 轻提示（成功/错误）、空态文案、二次确认
4. 演示数据与桌面端/游客 Web 原型完全对齐（房间 101–208、房型 128/168/198、预订号 R 前缀等）

## ❌ v1 明确不包含（柜台业务与新增功能点）

- 入住登记、退房结算、收款/押金收取——涉及钱与证件，必须回前台桌面端
- 房态变更操作（打扫完成、维修、停用）——回前台桌面端
- 消息通知 / 推送中心——现有数据库无承载表，本期不做（如后续需要需新增 `notification` 表）
- 客人档案管理、房间/房型档案维护、账号管理
- 报表导出、多门店管理
- 游客端功能（预订、查询）——由游客 Web 承担
