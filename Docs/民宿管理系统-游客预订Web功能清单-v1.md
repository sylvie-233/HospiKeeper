# 云栖民宿 · 游客在线预订 Web ｜ 功能清单（v1）

定位：面向游客的**轻量在线预订门户**，与民宿管理系统（桌面端）共用数据库、实时联动房态。主打「查房、预订、查询/取消预订」三件事。不涉及在线支付、会员体系。

> 对应原型：`Docs/酒店管理系统-游客预订Web原型-v1.html`（可直接双击打开，演示数据内置）
> 内部联动：`Docs/酒店管理系统-原型-v1.html`（桌面端）、`Docs/民宿管理系统-数据库设计-v1.sql`
> 版本：v1 ｜ 日期：2026-11-25

## 一、首页（营销 + 快速入口）

1. 品牌宣传区（Hero）
   - 民宿名称、位置卖点（西湖 · 南山路 · 独栋小院）、宣传语
   - 数据统计条：客房数、房型数、步行至湖边时间、住客评分
2. 快速查询条
   - 入住日期 / 退房日期 / 房型偏好三个条件 + 「查询可订房型」按钮
   - 查询后自动跳转「客房预订」页并带入所选条件
3. 精选房型卡片
   - 展示房型封面、名称、设施标签、简介、单价、按所选日期折算的合计价
   - 实时剩余间数角标（已订满置灰禁订）
4. 特色介绍（4 卡）：六种房型 / 灵活到店 / 到店支付 / 每日打扫
5. 入住须知（3 卡）：入住退房时间 / 预订与取消规则 / 押金与支付说明

## 二、客房预订（核心）

1. 日期查询：入住 / 退房日期 + 房型偏好筛选
2. 房型卡片列表：单价、共 N 晚合计、设施标签、简介、立即预订按钮
3. 实时可订量展示
   - 口径：可订数 = 该房型空闲房间数 − 与查询日期段重叠的未到店预订数
   - 剩余 N 间 / 已订满两种展示态，订满房型禁止预订

## 三、在线预订（核心流程）

1. 预订信息弹窗
   - 自动带出：房型、入住/退房日期、晚数、单价、预估房费
   - 录入：入住人姓名（必填）、手机号（必填，11 位校验）、身份证号（选填，18 位格式校验）
2. 提交预订
   - 生成预订号：`R + yyyyMMdd + 3 位序号`（与桌面端预定单规则一致）
   - 自动锁定一间空闲房 → 房态变为「预定」（与桌面端看板实时联动）
   - 预订免支付，房费与押金到店支付
3. 预订成功页
   - 高亮展示预订号、入住摘要
   - 到店提示（18:00 前到店、出示预订号或手机号）
   - 一键跳转「我的预订」

## 四、我的预订

1. 手机号查询：输入预订手机号查询单人全部预订记录
2. 记录列表：预订号、房型/房号、入住→退房日期、状态、操作
3. 预订状态（与数据库 `reservation.status` 一致）
   - 待到店（PENDING）：可在线取消
   - 已转入住（CONVERTED）：仅展示，到店由前台办理
   - 已取消（CANCELLED）：仅展示
4. 在线取消预订
   - 二次确认弹窗
   - 取消后房间恢复「空闲」，房量实时回补

## 五、公共能力

1. 页面导航：首页 / 客房预订 / 我的预订，胶囊式导航 + 当前页高亮
2. 操作反馈：轻量 Toast 提示（成功 / 错误），表单校验即时反馈
3. 弹窗体系：预订表单弹窗、预订成功弹窗（点击遮罩可关闭）
4. 响应式布局：≤860px 时查询条纵向堆叠、网格降列、导航简化
5. 页脚：品牌介绍、快捷导航、入住信息、联系方式

## ❌ v1 明确不包含（控制复杂度）

- 在线支付（预订金 / 全款）——到店支付模式
- 会员注册、登录体系、积分储值
- 发票、优惠券、营销活动
- OTA 渠道对接（美团、携程）
- 游客端修改已提交订单（改期/换房留二期）
- 短信 / 邮件通知
