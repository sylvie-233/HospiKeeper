# 简易酒店住宿管理系统｜功能清单（轻量版，不复杂，适合小宾馆 / 民宿）

定位：中小型民宿、小旅馆，不含复杂集团连锁、多门店、会员分销、财务 ERP，主打**开房、退房、房态、登记、账单**核心流程。

## 一、基础信息管理

1. 房间管理
   - 新增 / 编辑 / 删除房间：房号、楼层、房型（单人间 / 双人间 / 大床房）、床位数、标价、底价、押金标准、是否带窗、是否独立卫浴
   - 房间状态初始化：空闲、维修、停用
2. 房型管理
   - 房型名称、基础定价、备注
3. 操作员账号（简单权限）
   - 账号密码登录
   - 两种角色：前台（开房退房、登记）、管理员（增删房间、改价格、查全部记录）
   - 支持修改密码

## 二、房态看板（首页核心）

- 可视化房间状态：空闲 / 已入住 / 预定 / 打扫中 / 维修
- 点击房间卡片快速操作：开房、预定、退房、标记打扫
- 支持按楼层、房型筛选房间

## 三、入住登记（核心）

1. 散客入住
   - 录入客人姓名、手机号、身份证号
   - 选择房间、入住时间、预计退房时间
   - 自动计算：房费、押金、应收金额
   - 支持手动修改单价（议价）
   - 生成入住单
2. 预定管理
   - 新增预定：客人信息、预定房间、到店时间、联系电话
   - 预定到店后一键转入住
   - 取消预定记录
3. 同住人登记：支持添加多名同住人信息

## 四、在住 & 退房结算

1. 在住列表：查看所有当前入住客人、房号、入住时间、押金、应付
2. 退房操作
   - 实际退房时间录入
   - 自动核算房费（支持按天计费；简易版不做钟点房复杂阶梯价，可选加钟）
   - 押金抵扣、退款金额计算
   - 备注：物品损坏扣费、其他消费（简单杂费录入）
   - 完成退房，房间自动变回【待打扫】状态
3. 消费追加（简易）：入住期间额外消费，如矿泉水、泡面，录入金额并入账单

## 五、记录与查询

1. 入住记录：历史所有入住单，支持按房号、姓名、手机号、时间段检索
2. 退房账单记录：可查看每一笔结算明细
3. 操作日志：谁在什么时候办理开房 / 退房（简易记录）

## 六、统计报表（轻量化，不复杂）

- 当日营收汇总：开房数量、退房数量、总收入
- 时间段营收查询（按日期筛选）
- 房间入住率简单统计（可选）

## 七、附加小功能（可选，不想做可以砍掉）

- 打扫状态：保洁完成后，前台一键改成空闲房
- 单据打印：入住单、结算单（小票）
- 黑名单：录入闹事、逃单客人，登记提醒
- 钟点房模式：单独钟点房价格、固定时长计费

## ❌ 不包含（控制复杂度）

- 线上 OTA 对接（美团、携程）
- 微信小程序预订
- 会员积分、储值卡
- 采购、库存、员工工资、完整财务
- 多门店连锁管理
- 门锁对接、门禁系统
- 发票开具
